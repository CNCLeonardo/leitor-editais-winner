# Leitor de Editais para Winner

Ferramenta web para extrair e organizar informações de editais, avisos de dispensa e termos de referência antes do cadastro no Winner.

## Recursos da primeira versão

- upload ou arraste de PDF;
- leitura do documento diretamente no navegador;
- identificação dos principais campos do Winner;
- página de origem e nível de confiança;
- alertas para informações que exigem conferência;
- campos editáveis e botões para copiar;
- exemplo preenchido com o edital do Hospital Ophir Loyola;
- nenhuma informação ausente é inventada.

## Como usar

1. Abra a página da ferramenta.
2. Anexe um PDF com texto pesquisável.
3. Clique em **Analisar edital**.
4. Confira os campos marcados como **Conferir**.
5. Copie os valores para o Winner.

## Limitação atual

A primeira versão requer PDFs com texto pesquisável. O suporte a documentos digitalizados como imagem, por OCR, está previsto para uma próxima etapa.

Todo o processamento é feito no navegador. A ferramenta não armazena o edital.
